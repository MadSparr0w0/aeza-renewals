# Telegram: вход, личный кабинет и группы

## Начать пользоваться

Администратор создаёт участника или приглашает его на сайт. Открытой регистрации через Telegram нет.

На сайте: войти обычным способом → «Настройки» → «Привязать Telegram» → открыть бота → подтвердить привязку → вернуться в исходный браузер. В другой раз достаточно «Войти через Telegram» и подтверждения в боте. Пароль остаётся доступным запасным способом входа.

Из бота: `/login` → одноразовая ссылка на сайт → вход в существующий аккаунт → явное согласие связать показанные аккаунты. Ссылка действует десять минут. Ссылка содержит токен во фрагменте после `#`, который не отправляется в обычном HTTP-запросе страницы.

В настройках можно отключить связь. Это отзывает незавершённые подтверждения и другие сессии пользователя. Новый вход и чтение в боте проверяют актуальную привязку; смена `@username` Telegram не меняет личность.

## Личная переписка

`/start` или `/menu` открывают меню. `/payments` показывает платежи по месяцам, `/history` — отмеченные оплаты, `/summary` — итоги отдельно по RUB, USD и EUR. Поддерживаются страницы и переключение месяцев. При каждом запросе бот заново проверяет Telegram ID и текущего пользователя.

Участник читает только свои платежи. Администратор читает только свою команду. Создание расходов, изменение условий и отметки оплаты выполняются на сайте. Бот сам не присылает финансовые уведомления в личку: личные сообщения появляются в ответ на действия пользователя.

## Несколько групп

1. Связанный администратор добавляет бота в группы с правом отправлять сообщения.
2. В личке открывает `/chats` → «Выбрать группу» и использует штатный выбор Telegram.
3. Сервер через Bot API проверяет реальное название/тип группы, статус администратора и права бота.
4. Бот показывает отдельное подтверждение: в группу поступят имя ответственного, название расхода, сумма, валюта и срок. После согласия группа включается.
5. Для следующей группы повторить выбор. Поддерживается до 20 включённых групп на команду. Каждая отключается отдельно через бот или сайт.

Выбор одноразовый, действует десять минут и связан с пользователем приложения, Telegram ID, командой и текущим ботом. Одна активная группа не используется разными командами. Само добавление бота в группу не разрешает публикацию данных. В группах финансовые команды не раскрывают кабинет.

Старый мастер `/connect` на сайте оставлен как резервный способ: он заменяет группы только своей команды. Для добавления нескольких групп следует пользоваться `/chats`.

## Как устроено подтверждение входа

Это вход без пароля через связанную Telegram-личность, а не интеграция с корпоративным SAML/OIDC-провайдером. Для BotFather не требуется настраивать внешний OAuth-домен.

Сервер создаёт запрос на пять минут и два независимых секрета: короткий код для deep link бота и отдельный HttpOnly cookie исходного браузера. Бот запрашивает явное подтверждение в личке. Завершить запрос может только исходный браузер; для привязки дополнительно требуются прежняя сессия и CSRF. Подтверждение используется один раз. В базе хранятся хеши секретов, роль не берётся из Telegram-профиля.

Не подтверждайте вход, который не начинали сами. Токены привязки, cookie и ссылки подтверждения не следует пересылать.

## Очередь уведомлений

За три дня до срока или при позднем добавлении создаётся отдельное задание для каждого выбранного получателя. В задании зафиксированы chat ID и текущий бот. Оплаченные/прекращённые платежи пропускаются. Отключение одной группы отменяет её неотправленные задания, сохраняя другие группы.

`sent` не повторяется. При неоднозначном сетевом результате `unknown` не отправляется повторно автоматически: Telegram не предоставляет ключ идемпотентности для `sendMessage`. Уже опубликованные данные нельзя отозвать отключением группы.

Механизм deep links и штатного выбора чатов основан на официальной документации: [Bot Features](https://core.telegram.org/bots/features#deep-linking), [Telegram Bot API](https://core.telegram.org/bots/api#keyboardbuttonrequestchat).
