# Происхождение аватара Aéza

Источник текущего аватара — файл `aeza.jpg`, предоставленный пользователем для бота `@aezainkeep_bot`. JPEG используется без изменений. PNG получен только технической конвертацией формата. Генеративное рисование и загрузка удалённого аватара не использовались.

## Источник

- Предоставленный пользователем исходник: `aeza.jpg`.
- Формат и размер: JPEG, RGB, **640 × 640**, **10 239 байт**.
- SHA-256 исходника: `e3157309159098f90dd757a9204d3df55f788ae4eca0ea38c1c7cb2e6086097b`.
- Белый фон, поля, знак и все элементы композиции являются частью исходного изображения.

## Конвертация

`avatar.jpg` скопирован побайтно из исходного JPEG. Повторного JPEG-сжатия нет: байты и SHA-256 полностью совпадают с файлом пользователя.

`avatar.png` сохранён в PNG без потерь после декодирования этого же JPEG. Проверено точное равенство всех RGB-пикселей PNG и декодированного исходника. Размер остаётся **640 × 640**. Масштабирование, кадрирование, изменение фона/цвета, добавление полей, текста и эффектов не выполнялись.

Для технической PNG-конвертации использованы Python 3.12.14 и Pillow 12.3.0. Прежние версии аватара из SVG заменены текущими файлами. SVG `frontend/src/assets/aeza/mark.svg` остаётся самостоятельным ресурсом интерфейса и не является источником нынешнего Telegram-аватара.
