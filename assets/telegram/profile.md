# Профиль «Aéza · Контроль продлений»

Используется бот `@aezainkeep_bot`. Имя, описания, команды и предоставленный JPEG применены 24 октября 2026 года и проверены чтением Bot API. Исходные тексты хранятся в `profile.json`; последующее изменение файлов само по себе не публикует их в Telegram.

## Название

Aéza · Контроль продлений

## Краткое описание

Ручной учёт продлений серверов, хостинга и доменов. Сроки и напоминания.

## Описание

Тестовый модуль Aéza для ручного учёта продлений серверов, хостинга и доменов. Здесь доступны платежи, ближайшие сроки и просрочки по RUB, USD и EUR. Нажмите /start для меню. Доступ — только в подключённом чате. Оплата выполняется в официальном кабинете Aéza, а отметка оплаты — в веб-модуле. Баланс и состояние услуг не синхронизируются.

## Команды

| Команда | Описание |
|---|---|
| `/start` | 🗂 Открыть меню продлений |
| `/menu` | 🏠 Показать меню |
| `/summary` | 📊 Сводка расходов по валютам |
| `/payments` | 🧾 Платежи и продления за месяц |
| `/upcoming` | 📅 Ближайшие неоплаченные продления |
| `/overdue` | ⚠️ Просроченные неоплаченные продления |
| `/help` | ℹ️ Команды и правила доступа |

Бот отвечает на команды только в чате, разрешённом настройками сервера. Команды и кнопки служат для просмотра. Отметка оплаты в веб-модуле не проводит платёж у провайдера. Кнопка «Кабинет Aéza» открывает официальный кабинет, где пользователь входит отдельно.

Публичное меню содержит только `/start` и `/help`; полный список из семи команд задаётся для подключённого чата. Тексты по умолчанию и русская локализация совпадают. Аватар — JPEG, предоставленный пользователем и скопированный побайтно без графических изменений. PNG получен только конвертацией формата; происхождение и контрольные суммы приведены в `provenance.md`. Применение профиля описано в `docs/telegram.md` с обязательным `--expected-bot aezainkeep_bot`.
